# Learnify 🎓

Learnify is an AI-based learning platform inspired by Google Classroom that helps students manage classes, generate lecture summaries, and export study materials as PDFs.

## Features
- Class and course management
- AI-generated class summaries
- PDF generation for notes and summaries
- Student-friendly learning dashboard
- Organized study materials

## Setup

```bash
git clone https://github.com/Dakshin211/learnify.git
cd learnify
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
uvicorn main:app --reload
```
